# MuMu 探险助手

这是一个纯 Python 小工具，用于附加在 MuMu 模拟器目标窗口上方，并由你主动点击按钮后执行勾选的任务。

## 运行

```powershell
python mumu_adventure_assistant.py
```

也可以双击 `run_mumu_adventure_assistant.bat`。

## 功能

- 自动识别当前运行中的 `MuMuNxDevice.exe` 窗口，支持多开。
- 自动通过 `MuMuManager.exe info --vmindex all` 绑定多开实例和 ADB 端口。
- 每个运行中的 MuMu 目标窗口都会生成一个独立控制条，支持多开。
- 控制条附加在对应模拟器窗口上方，宽度跟随目标窗口，高度约为 260px。
- 优先用 MuMu 自带 `adb.exe` 做截图和点击：
  - 截图：`adb -s <serial> exec-out screencap -p`
  - 点击：`adb -s <serial> shell input tap x y`
  - ADB 不可用时才退回普通窗口截图和鼠标点击。
- 勾选任务后点击“开始任务”才会执行：
  - 检测左下角是否为“探险”入口或双剑标志，识别以双剑图标边缘和底栏图形色块为主，不依赖文字。
  - 符合条件就点击进入探险，不再判断红点。
  - 探险页领取按钮的固定绿色图块命中才点击，灰色则跳过。
  - 弹窗出现绿色按钮图块后再次点击。
- 获得奖励页出现后，点击空白处退出，再点击左上角返回上一层。
- 已加入“训练士兵”任务：
  - 自动展开左侧队列面板。
  - 依次处理盾兵、矛兵、射手。
  - 只处理“空闲中”和“已完成”，遇到倒计时训练中会跳过。
  - 进入训练页后选择最高可用等级，点击训练，再返回。
- 每一步点击后都会验证页面状态，验证失败会停止当前任务。
- 多个勾选任务会按顺序执行，任务间保留 3 秒缓冲；完成的任务文字会变绿。
- 每个面板提供“显示取色范围”调试开关，会在对应模拟器画面上显示本窗口使用的图形取色区域。
- “停止”按钮会向所有正在执行的窗口任务发送停止信号。
- 如果任务开始时不在主城界面，会先尝试点击左上角返回；主城判断使用左上小箭头和右下城镇/野外切换图标的图形特征。

## 调试

若某个分辨率下识别偏差，可以先打开“显示取色范围”确认框位，再调整 `mumu_adventure_assistant.py` 顶部的 ADB 坐标块和颜色容差。

默认 MuMu 安装路径提示为：

```text
D:\Program Files\Netease\MuMu\nx_main
```

程序实际识别运行中的窗口，不依赖固定安装路径。
